Q: 为什么没有声音？

A: 请检查以下几点：

  • 确认已安装 ffmpeg（Windows 用户）
  • 在"声卡管理"页面确认选择了正确的输出设备
  • 检查音箱/耳机是否正确连接
  • 确认音量未设置为 0
  • 点击"测试声卡"按钮检测设备是否正常
Q: Docker 中无法播放声音？

A: Windows 系统上 Docker 无法直接访问宿主机声卡，建议使用本地 Node.js 运行。Linux 系统需要挂载 /dev/snd 设备并配置 ALSA。

Q: Docker 下只识别到 NVIDIA 声卡，识别不到 Intel 声卡？

A: 这是 Docker 设备映射的问题。Docker 默认只会映射第一个可用的声卡设备。解决方法：

  • 方法一：启动容器时指定设备映射
  • --device /dev/snd:/dev/snd
  • 如果需要指定特定设备，可以查看 ls -l /dev/snd 确定设备名称
  • 方法二：使用 --privileged 权限（不推荐，安全性较低）
  • 方法三：在宿主机上禁用不使用的声卡，强制 Docker 使用指定的声卡

提示：可以使用 aplay -l 命令查看当前系统识别到的所有声卡设备

Q: 声卡不识别怎么办？（针对飞牛 fnOS）

A: fnOS 可能精简了 ALSA 或没有完整的音频驱动，可以尝试以下方法修复：

  • sudo apt install --reinstall alsa-utils pulseaudio -y - 重新安装 ALSA 和 pulseaudio
  • sudo modprobe snd-hda-intel - 加载声卡驱动
  • ls -l /dev/snd - 检查声卡设备是否存在
  • sudo usermod -aG audio `$USER - 确保当前用户有 audio 组权限
  • pulseaudio --start - 启动 pulseaudio 服务

提示：执行完上述命令后，建议重启服务器或重新登录用户会话

Q: Intel 声卡驱动安装和配置方法？

A: 如果系统识别不到 Intel 声卡，可以尝试以下步骤：

  • lspci | grep -i audio - 检查硬件是否被识别
  • aplay -l - 查看已加载的声卡设备
  • sudo apt install --reinstall alsa-utils pulseaudio - 重新安装音频工具
  • sudo modprobe snd-hda-intel - 加载 Intel HD Audio 模块
  • sudo usermod -aG audio `$USER - 确保用户有音频权限

如果模块正在使用中无法卸载，可以直接重新加载：

  • sudo rmmod snd-hda-intel && sudo modprobe snd-hda-intel

检查 /dev/snd/ 目录是否有 controlC0 等设备文件，存在说明声卡已识别。

Q: 如何备份音乐和配置？

A: 备份以下目录即可：

  • music/ - 音乐文件目录
  • config.json - 配置文件
Q: 支持哪些音频格式？

A: 支持 MP3、FLAC、WAV、M4A、OGG、WMA 等常见音频格式。只要 ffmpeg 支持的格式都可以播放。

Q: 如何更新系统？

A: 在关于页面点击"手动更新"，选择 ZIP 格式的更新包文件。更新完成后服务器会自动重启，数据不会丢失。

NAS本地音乐播放器

一个轻量级的本地音乐播放器，支持通过网页界面控制飞牛osNAS服务器，通过插入AUX音频或USB声卡设备，实现音乐播放。

功能特性

  • 📁 支持多种音乐格式（MP3, FLAC, WAV, M4A, OGG, WMA）
  • 🎵 播放/暂停/停止控制
  • 🔊 音量调节
  • 🎛️ 声卡设备管理
  • 📤 文件上传功能
  • 🔍 音乐搜索

使用说明

播放控制
  • 播放/暂停：点击底部播放栏的播放按钮，或使用快捷键
  • 上一首/下一首：点击左右箭头切换歌曲
  • 停止：停止当前播放，进度条归零
  • 播放模式：支持顺序播放、随机播放、单曲播放、单曲循环四种模式
  • 进度控制：点击进度条可跳转到指定位置播放
上传音乐
  • 点击顶部"上传"按钮打开上传对话框
  • 支持拖拽文件或点击选择文件
  • 单次最多上传 50 个文件，每个最大 500MB，总计最大 2GB
  • 上传的音乐自动保存到服务器 music/ 目录
  • 上传完成后播放列表自动刷新
搜索音乐
  • 在顶部搜索框输入关键词实时搜索
  • 支持按歌曲名称搜索
  • 清空搜索框显示全部歌曲
文件夹浏览
  • 切换到"文件管理"视图浏览音乐目录
  • 点击文件夹查看其中的音乐文件
  • 支持文件夹级别的播放控制

发声原理

音频播放流程
1
读取音频文件

服务器从 music/ 目录读取 MP3、FLAC、WAV 等格式的音频文件

↓
2
解码音频数据

使用 ffmpeg 将压缩格式的音频解码为 PCM 原始音频数据（S16_LE 格式，48kHz 采样率，双声道）

↓
3
输出到声卡

解码后的 PCM 数据通过管道传输到系统声卡播放器（ffplay/afplay/aplay），由声卡设备转换为模拟信号输出

↓
4
扬声器发声

声卡通过 AUX 音频线或 USB 连接音箱/耳机，将数字信号转换为声音

多平台播放方案
平台 播放器 说明
Windows ffplay 需要安装 ffmpeg，通过 audio_device 参数指定声卡
macOS afplay 系统自带播放器，无需额外安装
Linux ffplay / aplay 使用 ALSA 声卡驱动，支持硬件设备选择
Docker ffmpeg → aplay ffmpeg 解码后通过管道转发给 aplay 输出到 ALSA
声卡设备管理
  • 自动检测：程序启动时自动扫描系统所有可用的声卡设备
  • 设备切换：在"声卡管理"页面选择输出设备，设置即时生效
  • 设备测试：支持测试当前选中的声卡是否正常工作
  • 持久化：选择的设备会保存到配置，下次启动自动使用

提示：插入 USB 声卡或 AUX 音频线后，建议在声卡管理页面点击刷新按钮重新检测设备

音量控制原理
  • 前端网页通过 HTTP API 向服务器发送音量设置请求
  • 服务器保存音量值到配置文件（config.json）
  • 播放时通过播放器参数控制输出音量
  • 多客户端共享同一音量设置，修改后全局生效
